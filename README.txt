VisionSolver AI - Local Free MVP
--------------------------------

This archive contains a frontend (React + Vite + Konva) and a backend (FastAPI) for a local-only
Visual Problem Solver. It uses Tesseract for OCR, OpenCV for basic shape detection, and Ollama
(local) for language reasoning. All components can run without paid APIs.

Folder structure:
- frontend/: React app
- backend/: FastAPI app

See the provided run instructions in the project root or follow the steps provided by the assistant.
